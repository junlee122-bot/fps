# P2A-BLOCKER-002 — PATCH-002-E는 5개 지렛대로 달성 불가능

**상태:** P2A 재개 중단, 지시 대기 (PATCH-002-E: "이 5개로 30칸 전부에서 25% 여유를
확보할 수 없으면 다시 멈추고 보고하라")
**선행:** PATCH-002-A(k 도입)·B(산탄×THATCH 정지)·C(임계 유지)·F(에너지=피해)·G는
이의 없음. 본 보고는 **D+E의 파라미터 해가 존재하지 않음**에 관한 것이다.

---

## 1. 공집합 증명 — DMR 쌍의 구조적 비율 한계

표기: 체인 저항 `S = Σ tᵢ(1+dᵢ)|ln retainᵢ|`, 잔여율 `R = e^(−S/k)`.
E 밴드를 S/k로 옮기면: 관통 `≤ 1.6740` / 부분 `[2.1203, 3.6889]` / 정지 `≥ 4.1352`.

DMR의 두 요구 칸:
- `TILE+보토` **관통**: `S_TB / k₃ ≤ 1.6740`
- `EARTH_WALL 100mm` **부분**(하한): `S_E / k₃ ≥ 2.1203`

두 식을 나누면 **`S_E / S_TB ≥ 2.1203/1.6740 = 1.2666`** 이 필요하다.

그런데 보토(80mm)가 `EARTH_WALL` 상수를 공유하므로(P1의 태깅 선택 —
CONTRACT-NOTES P1-2에 기록) 두 저항은 같은 변수 ρ_E = |ln retain_E|로 묶인다:

```
S_E  = 10·1.8·ρE = 18ρE
S_TB = 3·1.55·|ln 0.60| + 8·1.8·ρE = 2.37535 + 14.4ρE
S_E/S_TB = 18ρE / (2.37535 + 14.4ρE)  <  18/14.4 = 1.2500   (모든 ρE에 대해)
```

**상한 1.25 < 필요값 1.2666** — ρE를 어떻게 잡아도(따라서 k·retain_C 5지렛대
전부를 어떻게 잡아도) 공집합이다. 실측 표: ρE=1.83→1.147, ρE=10→1.230,
ρE=100→1.248. (참고: PATCH-002-D의 시산값 retain_E=0.16으로는 카빈 TILE+보토가
'부분'이 아니라 '정지'가 되는 것도 같은 결합의 증상이다.)

근본 원인: **지붕 보토와 흙벽이 같은 재질 상수에 묶여 있는데, 유효 두께가
14.4 vs 18로 25%밖에 차이 나지 않아** 밴드 여유(26.66% 비율)가 들어갈 틈이 없다.

## 2. 권고 — 보토 표면 분리 (`ROOF_SOIL` 신설, 동결 변경 제안)

물리적으로도 보토(이완된 알매흙·강회다짐 이전 층)는 다진 심벽과 다른 재료다.
결합을 끊으면 문제 전체가 여유 있게 풀린다. **실행 검증 완료 — 30칸 전부 E 만족:**

ROOF_SOIL: { penClass: HEAVY, energyRetain: 0.455, density: 0.80, opaque: true,
  translucent: false, dynamicOpacity: false, breachable: true,
  fx: 'dust_burst', audio: 'muffled_thud', ricochet: 0.02 }

## 3. 비추천 대안 — 표 재정정 (DMR×TILE+보토 '관통'→'부분')

5지렛대만으로 성립은 하지만 해 공간이 퇴화한다 (실측):
- retain_EARTH ≈ **0.05**(흙벽 10cm의 저항이 판벽의 22배), retain_COLUMN ≈ 0.355
  (사실상 무변경 — D의 '상향' 취지 무산)
- 카빈×TILE+보토 R=2.54%(하한 0.4%p 밀착), 카빈×COLUMN R=1.57%(상한 0.4%p 밀착) —
  **E가 금지하려던 경계 밀착이 밴드 안쪽 경계에서 재발**한다.
정체성 손실(DMR이 지붕을 완전 관통하지 못함)까지 고려해 비추천.
