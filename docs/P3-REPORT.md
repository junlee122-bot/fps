  야간 하늘광 .65 → 0.59%.

## 5. 발주자 판단이 필요한 항목
0. **[최우선] 팔작지붕 프로파일 반전(P1 기하 결함) 즉시 수정 승인 여부.** R1 수정 검증 중 정점 프로브로 실증: 동헌
   지붕 셸이 처마 8.2 m·용마루 5.9 m의 **골짜기 형태**로 만들어져 있고(kit.js `yProfile`의 v 방향이 경사면 매개변수와
   반대), 마당에서 보이는 큰 지붕면은 뒤집힌 셸의 안쪽이다. 용마루 상자는 1.5 m 떠 있고 서까래 프롭은 3 m 아래에 있다.
   맞배지붕은 정상. C3의 "기하 정상" 판정은 오진(§4.4 위반, CONTRACT-NOTES R1-G1에 정정 기록). R1 지붕 결함(묶음 C·E)의
   대부분이 이 결함의 증상이고, 기와 상면은 팔작지붕에서 어떤 샷에도 보이지 않는다. **§9 동결 규칙대로 P3는 손대지
   않았다.** 최소 수정은 한 줄(`yProfile = (v) => eaveY + drop·v^sag`)이며, 승인되면 재캡처 뒤 R2를 돌린다. 미승인이면
   R2는 이 결함을 안고 진행한다(결과 정직 보고).
0-1. **창호지 렌더 모델(P0 동결 불투명도 .62) 재검토.** 창호지는 확산체인데 현재는 알파 블렌딩(투명체)이라 뒤 물체·격자가
   38% 그대로 비친다(R1 S03·S09 결함). P3는 계약대로 .62를 유지하고 역광 투과 발광만 추가했다(뒤에서 오는 태양광 ×
   종이색). 근본 해결은 "불투명 + 투과광 발광 + 뒤 물체 그림자" 모델로의 전환인데 이는 P0 물성(불투명도=피격 투과율
   상태)·P2A 이벤트 어휘·C2 §8 오버드로우 추정(반투과 면적)까지 걸친다 — 발주자가 P4 범위로 정할 항목.
1. **부팅 예산**: C3 계약 페이지 부팅 중앙값 13.1s(DPR2, SwiftShader), 잠정 8s 초과. 플레이 중 컴파일 0은 유지.
   저해상 단독 분해: 합성 2.4s + 프리웜 7.8s(첫 사용 JIT 지배). 감축 후보(품질 대가): 근접 재질 512²→256²(−0.8s),
   셰이더 변형 축소. PATCH-004-A 3항에 따라 최종 예산 확정 요청.
2. **§10 Apple Silicon 실측**(fps p50/p99·최악 프레임·부팅): 본 컨테이너 불가. 사용자 측에서 `node tools/profile.mjs`
   (계약 기본값) 실행 필요.
3. **팔레트 규율의 대가**: 크로마 .6 축소로 주간 지면(PACKED_DIRT)이 회색에 가깝게 읽힌다(육안). 규율 유지 vs
   흙 대역 상한 재검토는 발주자 판단(비평 라운드 결과와 함께).
4. 브리프 §2 비평 지시문 원문 부재 — `docs/critique/README.md`의 재구성본 승인 여부.
5. **외부 이미지·영상 생성 서비스(예: Higgsfield) 도입 여부** — 현행 계약(A3 아트 에셋 0개, 전면 절차 생성,
   런타임 의존성 three.js 단독, §6 포토리얼 함정)과 충돌하므로 P3에서는 도입하지 않았다. 도입하려면 계약 패치가
   선행되어야 하며, 권고안은 **참고 전용**(수묵·단청 색감 레퍼런스, 비평 비교 기준)으로 한정하고 참고 이미지는
   저장소에 넣지 않는 것이다. 출시물 텍스처 생성 용도는 색역·알베도 게이트를 깨기 쉬워 권하지 않는다.
   P4 지시 시 판단 요청(발주자 제기, 2026-09-17).

## 6. 정직한 한계
- 모든 성능 절대값은 소프트웨어 렌더러 스케일. 결정성·팔레트·알베도·프로그램 수·컴파일 0은 환경 무관 성질이다.
- 결정성은 SwiftShader에서 입증됐다. 실제 GPU 드라이버는 다른 비결정 경로(예: 병렬 리덕션)를 가질 수 있어 §10
  실측 시 baseline ×2를 실기기에서도 한 번 돌릴 것을 권한다.
- 비평은 브리프 원문 지시문이 아니라 재구성 지시문으로 수행된다(기록).
- C4 그레이드의 대역 채도 상한은 팔레트 규율을 룩이 강제하는 장치다 — 재질·조명 결함을 가릴 수 있으므로 C3에서
  재질(크로마)·조명(야간 하늘광)을 먼저 고치고 LUT는 2차 보호로 뒀다.
- 실시간 모드 시뮬 시간 소화율 지표는 profile 통계에만 있고 게이트가 아니다(C2 기록).
