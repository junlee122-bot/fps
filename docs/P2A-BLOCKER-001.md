# P2A-BLOCKER-001 — §2-1 결과 표는 에너지 튜닝으로 달성 불가능

**상태:** P2A 작업 중단, 지시 대기 (P2A-BRIEF §2-3: "에너지 조정으로 표를 만족시킬 수
없으면 작업을 멈추고 보고하라")
**검증 코드:** 본 문서의 모든 수치는 동결 `computePenetration()` 실행으로 산출했다.

---

## 1. 원인 — 분류가 에너지에 대해 불변이다

`computePenetration()`의 구조:

- 레이어 통과 후 잔여 = `energy × energyRetain^(thickness×(1+density))` —
  **잔여율(비율)은 표면·두께만의 함수**이고 에너지와 무관하다.
- 정지 임계 = `energy < energy0 × 0.02` — **초기 에너지에 비례**하므로
  이 또한 비율 조건이다.

§2-1의 분류 정의(관통 = 잔여 ≥ 초기의 15%, 부분 = 0~15%, 정지 = 0)도 전부 비율 기준.
따라서 **세 무기의 분류 결과는 에너지 값과 무관하게 항상 동일하다.**
탄자 수(산탄 9펠릿)도 각 펠릿이 같은 비율을 겪으므로 차이를 만들지 못한다.

## 3. 검토한 해결책과 판정

### R-A. 에너지 튜닝 (브리핑 지시 범위) — **불가능** (§1 증명)

### R-B. 정지 임계만 절대값(줄)으로 변경 — **불충분**
관통/부분 경계(15%)가 여전히 비율이라 "카빈이 판벽 관통(현재 잔여율 9%)"에 도달 불가.

### R-C. 무기별 관통 계수 k (채택 제안) — **30/30 달성 (수치 검증 완료)**
물리 래퍼가 지오메트리 실측 두께를 `thickness / k`로 스케일해 동결 함수에 전달한다.
물리적 해석: 탄자의 단면 밀도·AP 성능. `surfaces.js` **함수·상수 무수정**.
단독으로는 28/30이고, 2칸이 수학적으로 공집합이라 아래 2건의 계약 결정이 필요하다:

1. **산탄 × THATCH '부분' — 불가능.** 산탄이 판벽 45mm(잔여율 지수 −2.41)에 정지하면서
   더 강한 장벽인 초가 200mm(−7.19)를 부분 관통할 수는 없다 (단조성).
   성립하려면 초가 기준 두께가 67mm 미만이어야 하는데 비현실적.
   → **정정 제안: 이 칸을 '정지'로.** (산탄 펠릿이 20cm 이엉단에 먹히는 것이
   물리적으로도, "산탄은 종이와 천만 뚫는다"는 §2-2 정체성 서술과도 정합)
2. **DMR × (COLUMN 부분 ∧ EARTH 부분) — 창이 1% 차로 공집합.**
   필요 조건: |ln 잔여율| 비율 51.97/24.95 = 2.083 ≤ ln(0.02)/ln(0.15) = 2.062. 미충족.
   → **정정 제안: 정지 임계 0.02 → 0.018** (`surfaces.js` 상수 1개 — 동결 변경 제안).
   창이 2.117로 열려 k=13.0에서 두 칸 모두 '부분' 성립.
   (대안: 래퍼가 자체 임계로 재분류 — "computePenetration 출력이 유일 규범"
   [PATCH-001-B]을 사실상 포크하므로 **비추천**)

### 채택 파라미터 (R-C + 정정 2건, 30/30 실행 검증)
| 무기 | 관통 계수 k | 초구 에너지 (자유 파라미터, 데미지 필용) |
|---|---|---|
| 카빈 5.56 | **6.0** | 1,800 J |
| 산탄 12ga | **0.58** (펠릿당) | 200 J × 9 |
| DMR 7.62 | **13.0** | 3,400 J |

경계 여유 주의: EARTH×카빈 1.56% (정지, 임계 1.8%까지 0.24%p),
COLUMN×DMR 1.84% (부분, 0.04%p), EARTH×DMR 14.7% (부분, 상한까지 0.3%p) —
**의도적으로 타이트한 칸들이며 유닛 테스트가 경계를 고정해야 한다.**

## 4. 요청 — CONTRACT-PATCH-002 승인 여부

1. 무기별 관통 계수 k의 계약 편입 (래퍼 구현, 동결 파일 무수정)
2. `surfaces.js` 정지 임계 `0.02 → 0.018` (동결 파일 1상수 수정)
3. §2-1 표 정정: 산탄 × THATCH '부분' → '정지'

3건 승인 시 §2-1 표(정정본) 30/30이 성립하며 P2A를 재개한다.
다른 방향(표 자체의 재설계, 동결 유지 + 표 대폭 정정 등)을 원하면 지시 바란다.

## 5. 함께 발견된 신규 모호점

- **FABRIC·THATCH 기준 두께가 P1 두께표에 없다.** 매트릭스 검증에 킷 실측값
  (FABRIC 2mm 가정, THATCH 200mm)을 썼다. 유닛 테스트 고정 전에 계약 값 확정 필요.
