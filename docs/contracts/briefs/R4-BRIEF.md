# R4-BRIEF — P3 최종 라운드

**전제:** R3′ 기준선 확정, r4wt 병합 · 병합 후 점검 통과(`ecec7a8`), 프로그램 45.
**성격:** R4 요구사항 **통합본.** PATCH-011 ~ 014와 그 사이 전달문에 흩어진 판단을 한 문서로 모은다.
전달문으로만 전해진 판단은 이 문서로 **계약 원문이 된다.**
**이 라운드 뒤 P3를 닫는다.** R5는 없다(`PATCH-011-F`).

## 2. 판정 기준

### 2-1. 도구
- 비평 지시문: **원문 전용** (`PATCH-012-A`)
- 비평 해상도: **756 px 유지** — R3′와 비교하기 위함
- 순차 · 블라인드 · 재개 가능 프로토콜 그대로

### 2-2. 합격 판정
| 항목 | 기준 | 출처 |
|---|---|---|
| **합격** | **샷 3 · 9 제외 10샷 결함 수가 208건보다 감소** | 012-B, 014-E |
| 재편 성패 | **B 등급 11건**의 감소 여부 별도 보고 | 011-F 정정 |
| A 등급 9건 | 정성 보고 (§2-3) | 011-F 정정 |
| 샷 9 | 정성 판정 — **"찢긴 종이로 읽히는가, 유리로 읽히는가"** | 014-E |
| 샷 3 | R4가 새 정의의 첫 기준선 | 008-F |

### 2-3. A 등급(뷰모델) 정성 보고 기준
R3′ 비평가 관찰(S08 · S11)에서 가져온다.
1. 면 방향에 따라 명도가 달라 **빛을 받는 것으로 읽히는가**
2. 접지 그림자 · AO로 **씬에 붙어 있는가**
3. 프레임 최대 대비 영역이 되어 **주피사체보다 시선을 끌지 않는가**

**재질만 바꾸므로 A 등급 결함 수가 줄지 않는 것은 정상이다.** 기하는 P4B에서 에셋으로 교체한다(`PATCH-011-C`).

### 2-4. 추가 관찰 — 미완성 판정 전환
원문 비평가가 미완성의 직접 근거로 든 것은 **"완성된 요소와 플레이스홀더가 같은 프레임에 섞여 있음"**이다.
A · B 등급이 정확히 그 플레이스홀더다.

**미완성 판정이 뒤집힌 샷이 있는지**, 있다면 **그 샷에서 B 등급 수정이 한 역할**을 비평가 문장을 인용해 보고하라.

## 3. 작업 — 노출 등급 순 (`PATCH-011-A`)

### 작업 1 — [A] 뷰모델 재질
- 건메탈 · 폴리머 분리, 에지 마모
- **기하는 건드리지 마라** (P2 소유)
- **알베도 매니페스트 동반 갱신** — `albedoaudit` 편차 10% 검사 (`PATCH-014-F`)
- `viewmodelaudit` 조도비 1.0 ± 0.10 유지

### 작업 2 — [B] 파편 · 데칼 색과 모양
**색만 칠하면 사각형은 여전히 사각형이다.** 모양까지 바꾼다.

| 단계 | 내용 | 프로그램 |
|---|---|---|
| a | 프로파일 15종별 색 · 발광 | 0 |
| b | **프로파일별 종횡비 + 인스턴스별 회전각** (행렬만) — 핵심 | 0 |
| c | 알파 맵 — 부드러운 가장자리, 표면별 불규칙 실루엣 | +1 |
| d | **데칼(탄흔)** — 표면별 알베도 · 노멀. 흙벽 · 목재 · 화강암 · 기와의 탄흔이 서로 달라야 한다 | 에이전트 판단, 보고 |

- 방향 예: 나무 파편은 길쭉하게, 흙은 둥글게 퍼지게, 종이는 얇게 너풀거리게
- `fxaudit` 구별 축에 **모양**을 추가하는 것을 검토하라
- 색 · 모양 표는 `src/materials`에 두고 배선은 main.js — 디렉터리 소유권 준수
- **예외:** 낙하 기와는 빌보드가 아니라 강체 `BoxGeometry`다. 모양은 P3 범위 밖

### 작업 3 — [B] 총구화염 · 예광 · 트랜지언트 라이트
- 강도 곡선, 색온도(미사용 `colorK` 훅), 감쇠
- 총구화염의 **흰 사각형**도 작업 2처럼 알파로 모양을 준다
- 자발광 태그 마스크 · 팔레트 자발광 대역(`PATCH-007-C`) 유지

### 작업 4 — [C] 창호지 구멍 모델 — **게임 규칙 결함** (`PATCH-013-B`)

| 항목 | 규정 | 출처 |
|---|---|---|
| 상태 | 판마다 **구멍 목록** `[{u, v, r}]`. 불투명도는 파생값 | 013-B |
| 이벤트 | `surface:damage`의 `localUV` 사용. 이미 발행 중 | 013-B |
| 구현 | 해석적 유니폼 배열. **프로그램 수 불변** | 013-B |
| 콜라이더 | **찢어져도 유지.** 찢어짐은 시각 · 시야 메커닉 | 014-B |
| 반지름 | 무기별 상수. **값은 아래 동작으로 실측** | 014-C |
| 기존 상수 | 발당 −.09, 하한 .08 **폐기.** 기본 .95는 유지 | 014 스캔 |

**구멍 반지름 · 찢어짐 목표 동작** (`PATCH-014-C`)

| 조건 | 목표 |
|---|---|
| 카빈 구멍 하나 | 판에 바짝 붙어야 겨우 보임. **2.5 m에서 판독 불가** |
| 카빈 구멍 여러 개가 모임 | 2.5 m에서 쓸 만한 시야 |
| **산탄 한 발, 기준 거리 3 m** | 판이 찢어진다 |
| 산탄, 먼 거리 | 펠릿이 흩어져 구멍만 낸다 — **결함이 아니라 설계**(근거리 정체성) |

**판독 불가의 조작적 정의:** 대비 0.15 미만. 판독 가능 기준은 006-D 실측 .24 ~ .33.
측정은 `PATCH-008-B` 방식(대비 · 경계 폭)으로 한다.

**playtest 검사** (`PATCH-014-D`)
1. 임계 미만에서 N발 → 구멍 N개 (산탄은 펠릿 수)
2. 구멍 위치가 탄착 UV와 일치
3. 같은 사격 → 구멍 목록 바이트 동일 (결정성 창에 포함)
4. 임계 초과 → 찢어짐 상태
5. `resetState()`가 구멍 목록 · 찢어짐 상태를 완전히 비움
6. **음성:** 구멍 생성을 인위로 막으면 반드시 실패 — `harnesstest` 케이스 추가

**시점:** 반드시 P4C 전에 끝난다. 콩쥐 가젯이 이 모델 위에서 정의된다.

### 작업 5 — [D] 천장 무아레
텍스처 앨리어싱. 밉맵 · 필터링 · 주파수. 거의 모든 실내 샷에 있다.

### 작업 6 — [D] 병합분 확인
접지 AO, 기둥 결 해시, 단청 원경 페이드는 병합 완료. R4 캡처에서 효과만 확인.

### 작업하지 않는 것
- **창살 패턴 · 방향** — P1-DEBT 1순위. 방향만 먼저 뒤집으면 성긴 격자가 정면에 드러난다. P1에서 함께
- **D 등급 조명 · 렌더 일반** — P4에서 캐릭터가 들어온 뒤 P3-DEBT 회귀 패스에서
- **샷 재촬영으로 구도 수정** — 금지. 샷은 측정 도구다
