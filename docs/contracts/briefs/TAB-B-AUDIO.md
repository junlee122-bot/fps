# TAB-B — P4A 오디오 (병렬 작업 지시서)

**당신은 병렬 탭이다.** 다른 탭(A)이 지금 R4(P3 마감)를 진행 중이다.
당신의 일은 **P4A 오디오 하나**이고, A 탭과 **파일이 겹치지 않는 것**이 이 지시서의 전부다.

첨부: `P4-BRIEF.md` — **§2만 수행한다.** 나머지 절은 맥락으로 읽되 착수하지 마라.

---

## 0. 예외 선언

`P4-BRIEF` 서두는 "P3가 닫히기 전에 착수하지 마라"고 쓴다. **P4A에 한해 예외를 둔다.**

- 이유: 오디오는 이벤트를 소비할 뿐 렌더 · 재질 · FX(R4 범위)와 닿지 않는다 (`P4-BRIEF` §1)
- 조건: 아래 §2의 소유 경계를 지킨다. 경계를 넘어야 하면 **멈추고 보고**한다

## 1. 브랜치

- **최신 안정 `main`에서** `p4a-audio` 브랜치를 딴다. `r4-wip`에서 따지 마라 — R4 작업 중인 트리다
- 병합은 **당신이 하지 않는다.** R4 판정 후 A 탭이 순서대로 병합하고 전체 게이트를 돌린다

## 3. 작업 범위

`P4-BRIEF` §2 전체: 표면 체인 오클루전 · `BRONZE` 공명 · 공간 잔향 · `audioaudit` · 오디오 결정성.

액터가 아직 없다. **기존 발사 이벤트와 테스트 이미터**로 완결하라 (`P4-BRIEF` §1).

### 특히 확인할 두 가지
- **§2-1 소리 소재는 승인됐다. 지금은 CC0 라이브러리로 시작한다(1단계).** 소재는 GitHub `PanderMusubi/sound-effects-library-weapons` — 세 계열 대응표를 먼저 보고하라. 내려받을 수 없으면 보고하라 — 발주자가 받아서 넘긴다. **계열 → 파일 대응은 매니페스트 하나로** 두어, 나중에 유료 라이브러리(2단계)로 바꿀 때 코드가 안 바뀌게 하라
- **§2-2 두 번째 경로(우회).** 이 탭에서는 **인터페이스만** 만든다. 그래프는 P4B에서 생긴다. 그래프 없이 직선 경로만으로 완전히 동작해야 한다

### 이번 개정으로 추가된 것 — 알고 있어라
`P4-BRIEF` §4-3 「토끼의 간」 모드가 확정됐다. 오디오와 닿는 부분:
- 장독을 **여는 소리**, 총알에 **깨지는 소리** — 벽 너머에서 들려야 하는 정보다
- 흥부 변장 중에도 **발소리는 흥부 그대로** (§4-1-C) — 간파 단서다

이것들은 **구현하지 마라**(P4C 범위). 다만 이벤트 → 오클루전 경로가 이런 소리를 **추가 코드 없이** 받을 수 있게 짜라.

## 4. 절차

1. 커밋 직후 **착수 전 모순 · 모호 스캔**을 먼저 보고한다 (`PATCH-014-A`)
2. 구현
3. `audioaudit` 음성 테스트 포함 통과 · 해시 2회 동일 · `npm test`
4. **보고는 두 번뿐이다: 완료했을 때, 막혔을 때.** 진행 중계는 하지 마라 — 발주자가 모든 보고를 손으로 옮긴다
