# P1 회귀 패스 후보 목록 (PATCH-009-C 개설 2026-09-18, PATCH-011-D 재정렬 2026-09-19)

P1(레벨·지형·킷 형태·소품 배치) 소유 항목이 별도 패스가 필요한 규모에 도달해 개설한다. **여기 항목은 지금 고치지 않는다.**
착수 시점은 **P4 종료 후 판단**한다 — P4 가 액터·가젯으로 월드 요구사항을 바꿀 수 있으므로 그 전에 P1 을 손대면 두 번 한다.
**단 창살(1번)만은 R4 종료 시 P4B 이전 처리 여부를 재판단한다**(011-D) — `silhouetteaudit` 이 창살 뒤 실루엣을 재기 때문이다.

순서는 **화면 노출 등급**(PATCH-011-A) 순이다. 등급은 작업 순서만 정하고 합격선은 바꾸지 않는다.
