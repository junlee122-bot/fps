# P3 비평 라운드 절차 (P3-BRIEF §2)

**[PATCH-012-A] 지시문은 원문으로 복귀했다.** R1–R3 는 원문이 리포에 없어 재구성한 5항목 판본으로 측정했다(계약 위반).
계약 번들 수령으로 원문 §2-3(4항목)을 확보했고, **R3′ 재기준선부터 R4·이후 전부 원문만 쓴다.** 재구성본은 아래 부록에
"재구성본 계측"이라고 표시해 보존한다 — R1→R2→R3 추이는 같은 도구로 잰 것이라 유효하지만, **R3′ 이후 수치와 절대값을
비교하지 않는다**(PATCH-012-C).

## 규칙
- 비평자 1명 = 1세션(독립 컨텍스트). 샷별로 **엄격히 순차** 실행 — 병렬 금지.
- 비평자는 **이미지만** 본다. 브리프·의도·샷 이름의 의미·이전 라운드 결과를 주지 않는다(블라인드).
- 비평자는 **증상만** 기록한다. 원인 진단·수정 제안은 금지(오너가 진단한다).
- 결함 수가 1차 지표, 점수(1–10)는 2차 지표. 샷이 "미완성"으로 읽히는지는 **기록만** 한다(PATCH-005-A: P5 종료 조건으로 이관).
- 라운드 판정(PATCH-005-A, R4부터): 직전 라운드 대비 **결함 총 개수 감소 = 통과**, 증가·정체 = 실패. R3는 팔작지붕 반전 수정으로 기와
  상면이 처음 평가되므로 증가를 실패로 보지 않는다(첫 정직한 측정). ~~미완성 판정 샷 > 3 → 실패~~ 는 R1·R2에 적용된 구 규칙(작성자 오류).
- **[PATCH-008-F]** R3 → R4 비교는 샷 3(`hanji_silhouette`)을 제외한 **11샷**으로 한다 — 샷 3 은 R4 에서 실내 광원 폐색 구성으로 재정의되므로
  R3 결함과 비교 불가. 샷 3 은 별도 기록하고 R4 가 그 샷의 새 기준선이다(지오메트리·샷 정의가 바뀐 대상은 그 변경 이후가 첫 정직한 측정).
- 지시문에 소유권 주석을 넣지 않는다(순수 반응 유지). 결함의 소유 분류(P3 / 타 패스 / 분류 불가)는 오너가 사후 수행하고 P3 소유분만 수정한다.
- **소유 분류 기준은 하나 — 그 결함을 고치는 코드가 어느 서브시스템에 있는가.** 게임 개정(PvP·캐릭터·에셋, PATCH-009/010)을 이유로 "나중에 바뀔 것"이라며
  P4 버킷에 넣지 않는다. 미래 추정은 근거가 아니다(빈 마당 = world/P1 소유; 처분은 P1-DEBT 에서). 기록이 먼저, 처분은 나중.
- **[PATCH-011-A]** 결함마다 **화면 노출 등급**을 부여한다 — A 상시(뷰모델·HUD) / B 교전(총구화염·예광·파편·탄흔) / C 시그니처(창호지·창살·실루엣)
  / D 공간(벽·바닥·천장·기둥) / E 원경(원경 지붕·하늘·안개). **수정 순서는 A → B → C → D → E**, 같은 등급 안에서는 심각도 순. 등급은 작업 순서만
  정하고 **합격선은 바꾸지 않는다**(판정은 여전히 결함 총 개수 감소). 근거: R3 비평은 116 건을 동일 무게로 기록해 뷰모델 지적이 1/116 으로 묻혔다 —
  "정보는 있었고 가중치가 없었다".
- **[PATCH-011-F → PATCH-012-B 로 대체]** **R4 를 P3 의 마지막 비평 라운드로 한다. R5 는 없다.** R4 종료 후 남은 P3 소유 결함은 `docs/P3-DEBT.md` 로
  이관하고 P3 를 닫는다. **판정은 R3′ → R4 비교로 내린다**(재구성본 R3 와 비교하지 않는다):
  결함 총 개수 감소 = 통과(샷 3 제외 11 샷, PATCH-008-F) · **B 등급 감소 여부를 따로 보고**(재편 성패는 이것으로 판단) ·
  A 등급은 정성 보고("뷰모델이 자리표시자에서 스타일라이즈드로 이동했는가" — A 등급 결함 수가 줄지 않는 것은 정상이다. 기하는 011-C 로 P4B).
  R3′ 의 등급·소유 분류는 **새로 부여한다** — 결함 목록 자체가 다르므로 R3 것을 옮기지 않는다(PATCH-012-B 3 항).
- **[PATCH-011 §1]** 게이트는 "정확한가"를 재고 "눈에 띄는가"는 재지 않는다. **매 패스 종료 시 발주자가 캡처를 직접 열람한다**(비평 전후 무관).
  보고서는 화면을 대체하지 못한다.
- **[발주자 지시 2026-09-19] 구도 결함 분류**: 순수 카메라 구도(수평선 이등분·정중앙 대칭·프레임 잘림·빈 근경)는 **`[계약]`(샷 계약)** 으로 분류하고
  P3-DEBT 에 넣지 않는다 — 게임에서는 플레이어가 카메라를 움직인다. 환경 자체에 시선 고정점이 없는 것(빈 마당·원경 부재)은 **world 소유**다.
  **샷을 다시 찍어 구도를 고치지 않는다 — 샷은 측정 도구이며 바꾸면 R3′ → R4 비교가 깨진다.**
- **[발주자 지시 2026-09-19] R4 보고 추가 항목**: 결함 수·B 등급 증감과 별도로 ① **미완성 판정이 뒤집힌 샷이 있는가**(R3′ 12/12 대비)
  ② 뒤집혔다면 그 샷에서 **B 등급 수정이 어떤 역할을 했는가**(계측자 문장 인용). 근거: 원문 계측자들이 미완성의 직접 근거로 반복해서 든 것이
  "완성 요소와 플레이스홀더의 디테일 밀도 불일치"이고, 이것이 A·B 등급과 정확히 겹친다.
- 각 샷 결과는 `docs/critique/R{round}-S{shot}.md`에 **즉시** 기록한다(세션 중단 대비, 파일 단위 재개).
- 오너는 결함을 결합 관심사(조명·색·톤 / 재질 / 지오메트리 / fx)별로 묶어 **순차** 수정하고, 수정·기록·
  이월(P4)로 분류한다. §6 포토리얼 함정: "사실적 표면 디테일 추가"류 수정은 반려, "의도가 읽히게" 수정만 채택.
- §9 지오메트리 동결: 형태 결함은 P1 소유물이라 이월 기록(수정 금지).

## 블라인드 지시문 — **원문 (P3-BRIEF §2-3). 각 비평가에게 정확히 이것만 준다**

```
이 이미지 하나를 평가하라. 다른 이미지나 프로젝트 의도는 주어지지 않는다.

1. 이 프레임은 "의도된 스타일"로 읽히는가, "미완성"으로 읽히는가. 하나를 골라라.
2. 프레임을 망치는 결함을 전부 열거하라. 각 항목은 관측 가능한 서술이어야 한다.
   ("먼지 텍스처가 필요하다" ✗ / "기둥과 벽의 밝기가 구별되지 않는다" ✓)
3. 결함 개수를 명시하라.
4. 10점 만점 점수.

원인을 추측하지 말고, 수정 방법을 제안하지 마라.
```

전달 방식만 환경에 맞춰 덧붙인다(이미지 경로 한 줄 + "이 파일 하나만 Read 하고 다른 파일·디렉토리를 열지 마라").
지시문 본문은 한 글자도 바꾸지 않는다.

### 부록 — 재구성본 (R1–R3 에 사용, 더는 쓰지 않는다)

5항목 판본이었다: ① 결함 목록(증상만) ② 결함 수 ③ 완성/미완성 ④ 점수 1–10 ⑤ 장소·시간대·분위기(원문에 없음).
1번 질문이 "완성된 게임 화면으로 읽히는가"여서 **콘텐츠 완성도**를 묻는 말투였고, 원문은 **스타일 판단**을 묻는다.
교정 실측은 `INSTRUMENT-CALIBRATION.md`.

```
# R{n} — {shot}

- 결함 수: N / 판정: 완성|미완성 / 점수: S
```
## 라운드 집계 (`R{n}-SUMMARY.md`)
샷별 결함 수·판정·점수 표, 결함 묶음(관심사별), 처리 분류(수정/기록/이월), 다음 라운드 여부.
