# 비평 지시문 교정 — 원문(P3-BRIEF §2-3) 대 재구성본 (2026-09-19)

## 발견

계약 번들(`docs/contracts/`) 수령으로 **비평가 지시문 원문**을 처음 확보했다. R1–R3 에 쓴 것은 원문이 아니라 재구성본이다
(`docs/critique/README.md` 머리말에 "원문이 남아 있지 않아 재구성"이라고 기록돼 있었다). 차이:

| | 원문 §2-3 | 재구성본 (R1–R3 사용) |
|---|---|---|
| 항목 수 | 4 | 5 |
| 1번 질문 | "이 프레임은 **의도된 스타일**로 읽히는가, 미완성으로 읽히는가" | "**완성된 게임 화면**으로 읽히는가, 미완성(플레이스홀더·테스트 장면)으로 읽히는가" |
| 순서 | 판정 → 결함 열거 → 개수 → 점수 | 결함 열거 → 개수 → 판정 → 점수 → **장소·시간대·분위기** |
| 결함 지시 | "프레임을 **망치는** 결함을 **전부** 열거" + 관측 서술 예시(✗/✓) | "눈에 보이는 결함" + "**증상만**(원인·수정안 금지)" |
| 추가 질문 | 없음 | 5번 장소·시간대·분위기 (원문에 없음 — 내가 추가) |

원문은 "각 비평가에게 **정확히 이것만** 준다"고 못박는다. 계약 위반이며 R1 부터 지속됐다.

## 교정 측정 (같은 이미지, 두 지시문)

| 샷 | 재구성본 (R3 기록) | 원문 | 결함 비 | 판정 | 점수 |
|---|---|---|---|---|---|
| S01 courtyard_noon | 12 | **23** | ×1.92 | 미완성 = 미완성 | 3 = 3 |
| S10 corridor_columns | 11 | **21** | ×1.91 | 미완성 = 미완성 | 5 → 3 |

- **결함 수는 약 1.9 배로 늘어난다.** 두 샷에서 비가 1.92 · 1.91 로 거의 같다.
- **판정은 바뀌지 않았다.** 내가 세운 가설("완성된 게임 화면"이라는 어형이 미완성 쪽으로 편향시킨다)은 **이 두 샷에서 지지되지 않았다.**
  원문 어형으로도 두 샷 모두 미완성이다. 가설을 취소하고 그대로 기록한다.
- 점수는 같거나 낮아졌다(S10 5 → 3).
- 늘어난 항목의 성격: 원문은 **구도**(수평선 이등분·정중앙 대칭·프레임 잘림)와 **깊이·색 범위**를 결함으로 세고, 재구성본에서는 거의 나오지 않았다.
  "전부 열거하라"와 관측 서술 예시가 열거 밀도를 올린다.

## 판단

- **라운드 간 추이(R1 157 → R2 131 → R3 116)는 같은 도구로 측정했으므로 유효하다.** 도구를 바꾸면 그 추이와 끊긴다.
- R4 는 PATCH-011-F 의 마지막 라운드이고 판정이 **B 등급 감소**에 달려 있다 — 비교 가능성이 판정의 전제다.
- 따라서 **R3 를 원문 지시문으로 재기준선(re-baseline)한다**: 이미 저장된 R3 축소본 12 장에 원문 지시문으로 블라인드 세션을 다시 돌려
  `R3O-S{nn}-*.md` 로 기록한다. 렌더가 없으므로 캡처·게이트 큐와 무관하다. 그러면 R4 는 **원문 지시문으로 돌리면서도**(계약 준수)
  R3O 대 R4 비교가 성립한다. 재구성본 기록(R3-S*)은 R1·R2 와의 추이용으로 보존한다.
- R4 판정 기준선은 **R3O 의 11 샷 합계**(샷 3 제외, PATCH-008-F)로 갱신한다. 등급별 기준선(A·B·C)도 R3O 기준으로 다시 센다.

발주자가 다른 판단을 내리면 그것을 따른다 — 이 문서는 선택지를 수치로 만든 것이다.
