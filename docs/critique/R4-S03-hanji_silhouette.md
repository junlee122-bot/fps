1. 격자문 뒤 실내가 균일한 연회색 평면이다. 바닥선·천장선·깊이 단서가 없어 "막대 뒤에 세운 발광 카드"로 읽힌다.
2. 왼쪽 문짝 뒤 상단의 크고 흐릿한 어두운 덩어리는 윤곽이 없어 사람·기물·그림자 중 무엇인지 식별되지 않는다.
3. 왼쪽 문짝과 오른쪽 문짝 뒤의 실내가 다르다. 오른쪽에는 세로 살대와 밝은 직사각 영역이 보이고 왼쪽에는 아무것도 없어 두 문짝이 같은 방을 묘사하지 않는다.
4. 발광하는 문이 주변을 비추지 않는다. 문 바로 앞의 마루 상판, 문지방, 문 양옆 기둥 면이 장면의 다른 부분과 같은 어둡기다.
