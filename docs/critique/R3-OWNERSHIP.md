변경 금지), `[불가]` = 크롭으로도 정체 미확정. 항목마다 주 소유 하나만 세고 부 소유는 괄호에 적는다. 비평자에게는 소유권을 주지 않았고 분류는 오너 사후
수행. 원문은 `R3-Sxx-*.md`. † = 원본 크롭으로 정체 확인(하단 각주).
